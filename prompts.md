AI assistance was used as a development aid during the IssueFlow backend assignment.

The assistance was used for requirement analysis, backend design, implementation guidance, debugging, local setup, testing, and documentation. The final code was reviewed, tested, and submitted under my responsibility.

## Main Prompts Used

### 1. Requirement Analysis
Analyze the IssueFlow backend requirements and identify the main modules, entities, validation rules, API endpoints, and extended features required for the Java Spring Boot implementation.

### 2. Backend Architecture
Design a clean Spring Boot backend structure using controllers, services, repositories, DTOs, entities, security configuration, and centralized exception handling.

### 3. Authentication and Authorization
Implement JWT-based authentication, including login, logout, token validation, protected endpoints, and retrieving the currently authenticated user.

### 4. Core API Implementation
Implement the REST APIs for user management, project management, ticket management, and comment management according to the provided API contract.

### 5. Business Rules
Implement ticket lifecycle rules, including valid status transitions, preventing updates after DONE, optimistic locking, role validation, and input validation.

### 6. Extended Features
Implement audit logging, ticket dependencies, attachments, CSV import/export, soft delete and restore, comment mentions, automatic overdue escalation, and automatic ticket assignment by workload.

### 7. Debugging and Local Setup
Debug local development issues related to Java 21, Maven, Docker Desktop, PostgreSQL, Spring Boot startup, and application configuration.

### 8. Testing
Create and run Spring Boot tests to verify key application behavior and confirm that the project builds successfully.

### 9. Documentation
Prepare setup, build, run, and testing instructions for `run.md`, and document the AI-assisted development process in `prompts.md`.
